# Parcele Aqui — Design System

> Documento vivo · v1.0 · Foundation
> Owner: Time Parcele Aqui · Maio 2026

A fonte da verdade visual e estratégica do Parcele Aqui. Tokens, componentes, princípios e diretrizes que conectam toda interface — landing pages, home, chatbot, painel de parceiros.

## Acesso

Documento HTML standalone, navegável diretamente no navegador. Suporta dark/light mode com persistência local.

## Estrutura

- **Filosofia, Missão e Voz** — princípios não-negociáveis
- **Autoridade Potencial Tecnologia** — chancela e argumentos de segurança
- **Marca** — logo, tom de voz, personas e funil GTM
- **Foundations** — cores, tipografia, spacing, radius, sombras, motion
- **Componentes** — botões, inputs, cards, badges
- **Aplicação** — metodologias, regras críticas, guias Figma e Framer
- **Roadmap** — próximas versões

## Stack referenciada

- **Design:** Figma (fonte da verdade dos componentes)
- **LPs:** Framer (assinatura ativa do time)
- **Home/Chatbot futuro:** Next.js + TypeScript + Tailwind
- **Backend:** Supabase
- **IA:** Claude API + OpenRouter
